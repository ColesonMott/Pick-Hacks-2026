Modular Urban Roads Documentation

Use the included package HDRP_UrbRoads.unitypackage for HDRP versions of the assets.

Modular Urban Roads contains road shaders for both URP and HDRP.
These use a basic triplanar implementation for texturing the roads.

In case you want to create custom materials with these shaders,
the properties for LitRoadTriplanarURP and LitRoadTriplanarHDRP are listed below.




LitRoadTriplanarURP:

Base Color
-	This is the base color texture for the road.

Metallic Map
-	This is the metallic map for the road. This texture controls both the metallic and smoothness of the material. The metallic information is stored in the R channel of the texture, and the smoothness information in the alpha channel.

Metallic Strength
-	The metallic information from the metallic map is multiplied by this value. This can range from 0-1,
where 0 would make the material completely non-metallic, and 1 retains the full metallic information from the texture.

Smoothness Strength
-	The smoothness information from the metallic map is multiplied by this value. This can range from 0-1,
where 0 would make the material completely non-smooth, and 1 retains the full smoothness information from the texture.

Normal Map
-	This is the normal map for the road.

Normal Strength
-	This number controls the strength of the normal map effect, and can be greater than 1.

Tiling
-	This number controls the tiling of all the textures. Using this property you can make the texture repeat more or less over a given distance.




LitRoadTriplanarHDRP:

Base Color
-	This is the base color texture for the road.

Mask Map
-	This is the mask map for the road. This texture controls both the metallic and smoothness of the material. The metallic information is stored in the R channel of the texture, and the smoothness information in the alpha channel.
The shader only makes use of the R channel and alpha channel of the Mask Map.

Metallic Strength
-	The metallic information from the mask map is multiplied by this value. This can range from 0-1,
where 0 would make the material completely non-metallic, and 1 retains the full metallic information from the texture.

Smoothness Strength
-	The smoothness information from the mask map is multiplied by this value. This can range from 0-1,
where 0 would make the material completely non-smooth, and 1 retains the full smoothness information from the texture.

Normal Map
-	This is the normal map for the road.

Normal Strength
-	This number controls the strength of the normal map effect, and can be greater than 1.

Tiling
-	This number controls the tiling of all the textures. Using this property you can make the texture repeat more or less over a given distance.
